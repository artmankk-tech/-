# QUEST｜習慣と仕事のRPG

ビルド不要の静的Webアプリです。記録は端末内に保存します。

## GitHub Pagesで公開

1. GitHubで新しいPublicリポジトリ（例：quest）を作ります。公開ファイルは誰でも見られるため、個人情報・業務情報・バックアップJSONを入れないでください。
2. Add file → Upload files から、ZIPを展開した中身をアップロードします。index.htmlをリポジトリ直下に置き、Commit changesで保存します。
3. Settings → Pages → Deploy from a branchでmainと/(root)を選択してSaveします。
4. 公開完了後、Pagesに表示されるHTTPSのURLをiPhoneのSafariで開きます。
5. 共有メニュー → ホーム画面に追加 → QUESTを起動します。アプリ内にも使い方ガイドがあります。

## 更新

1. アプリからJSONバックアップを保存します。
2. 更新ファイルを同じリポジトリの同じ場所へアップロードします。
3. HTML・JS・CSS等の更新時はsw.jsのCACHEを新しい値（例：quest-pwa-v4）にし、すべて同じCommitに含めます。
4. Pagesの更新完了後、オンラインでアプリを開き、一度閉じて開き直します。必要なら再読み込みします。更新中の画面は旧版の場合があります。
5. 両モードの記録を確認します。バックアップ前にサイトデータを削除しないでください。

## 保存・復元と仕様

- 仕事／プライベートでミッション・XP・報酬・日別記録・タイマーを分けます。
- ☆で重要なミッションを3件まで選べます。未達成に罰則はありません。
- 日付は端末のローカル日付です。累積XPは日付変更、ミッション編集・削除でも維持します。当日のチェック取り消しでは、その達成分を取り消します。
- 旧保存キーquest-rpg-v1を継続使用します。旧データから達成XPを移行し、移行前原本はquest-rpg-v1-pre-upgradeに保持します。旧版ですでに失われたXPは復元できません。
- 2分着手・15分集中を選べます。モード切替後も各タイマーが進み、開始したモードへ加算します。タイマー完了の10 XPは各モード1日1回。再開5 XPは各モード1日3回までです。
- タイマーは画面復帰時に実経過時間で更新します。通知・音はありません。アプリ終了・再読み込みでタイマーは失われます。日をまたぐタイマーには加算しません。
- 報酬は累積XPで解放し、XPは消費しません。各報酬は各モード1日1回です。
- 毎週・更新前・復元前にJSONバックアップを「ファイル」アプリなどに保存してください。復元は両モードを置き換えます。形式を検証し、保存成功後に切り替えます。復元直前の原本はquest-rpg-v1-before-restoreにも保持します。
- 保存エラー時はJSONバックアップを直ちに保存してください。画面の操作結果が再起動後も残るとは限りません。既存データの読み込みに失敗した場合は自動上書きを停止します。
- Safariとホーム画面アプリで保存領域が異なる場合があります。ホーム画面側でも記録を確認してください。プライベートブラウズは避けます。同期はありません。
- 初回オンライン起動でオフラインファイルを準備します。キャッシュが消えた場合はオンライン起動が再度必要です。

## 開発・テスト

構成：index.html、style.css、app.js、manifest.webmanifest、sw.js、icon-192.png、icon-512.png。外部サービスやビルド工程はありません。

ローカル確認：このフォルダーで `python -m http.server 8000 --bind 127.0.0.1` を実行し、http://127.0.0.1:8000 を開きます。

自動テストはNode.js・Playwright・Chromiumがある環境で `node tests/browser.cjs` を実行します。Chromiumの場所はテスト内のexecutablePathを環境に合わせます。利用者に開発ツールは不要です。
